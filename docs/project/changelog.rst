Changelog
=========

All notable changes to ``samplepaths``, most recent first, with one page per
minor version. Times were measured as described in
:doc:`/guide/performance`.

Changes which are merged and not released yet are listed here, under a
heading "Unreleased". At a release they move to the page of their version.
